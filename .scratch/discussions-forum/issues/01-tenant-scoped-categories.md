# 01: Tenant-scoped categories

**What to build:** Active choir members can browse the categories available to them, and authorized members can manage choir-wide or ensemble-restricted categories.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Only active members of the current choir can access its forum categories.
- [ ] Choir-wide categories are visible to all active members; ensemble-restricted categories are visible only to active members of the selected ensembles.
- [ ] Members with the category-management ability can create, edit, and delete categories; other members cannot.
- [ ] Category listing and management behavior is available through the tenant-facing interface.
- [ ] Feature coverage verifies tenant isolation, ensemble visibility, and category authorization.
